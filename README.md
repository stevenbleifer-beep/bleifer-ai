# bleifer.ai

Placeholder page for **bleifer.ai**, hosted on GitHub Pages.

- Static HTML/CSS, no build step. Edit `index.html` / `style.css` and push to `main`.
- Animated GIFs in `img/` were generated by the script in `tools/make_gifs.py` (needs Pillow).
- `CNAME` pins the custom domain. Don't delete it — GitHub Pages reads it on every build.
